# Spec Delta

## REMOVED Requirements

### Requirement: Catálogo de componentes
**Reason**: O catálogo de componentes não traz ganho proporcional ao custo neste projeto; a revisão visual acontece no protótipo e o comportamento é coberto por testes de componente e e2e.
**Migration**: Nenhuma ação: componentes são verificados por testes (Vitest + Testing Library e Playwright) nos dois temas e idiomas quando o cenário pedir.
