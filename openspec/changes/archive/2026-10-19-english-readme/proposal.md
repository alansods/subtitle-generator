# Proposal

## Why

O repositório é público no GitHub e o público dele lê inglês. O README estava em português e sem imagens, e o nome do repositório também estava em português.

## What Changes

- README reescrito em inglês, com capturas do fluxo completo (início, gerar, gerando, revisar, baixar legenda, baixar vídeo, pronto) em `docs/screenshots/`.
- Repositório renomeado para `subtitle-generator` no GitHub; `name` do `package.json` e do `package-lock.json` acompanha.

### Fora do escopo
